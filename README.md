# GCV & Quantity Manager

A comprehensive Excel-like spreadsheet application for managing GCV (Gross Calorific Value) and Quantity across 30 sets (Pile-1 to Pile-6, A-E each).

## Features

- **30-Set Spreadsheet**: Track GCV and Quantity for Pile-1 through Pile-6 (A-E each)
- **Weighted GCV Calculation**: Automatically calculates weighted average when merging lots
- **Quantity Management**: Add new lots, merge with existing, or subtract quantities
- **Date History**: Save and restore data snapshots by date
- **Visual Indicators**: Color-coded piles and sub-labels for easy identification
- **Local Storage**: Data persists in browser localStorage

## Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: Shadcn UI (Button, Input, Label)
- **Icons**: Lucide React
- **Date Handling**: date-fns
- **Build Tool**: Vite
